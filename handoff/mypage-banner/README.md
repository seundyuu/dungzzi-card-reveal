# 마이페이지 「실록 보기」 배너 — 개발 전달

Figma: https://www.figma.com/design/v0xiKAQUwlHE8HjFCICDpQ?node-id=302-923 · Figma 폭별 미리보기: https://www.figma.com/design/v0xiKAQUwlHE8HjFCICDpQ?node-id=302-924 · 웹 미리보기: https://seundyuu.github.io/dungzzi-card-reveal/handoff/mypage-banner/preview.html

배너를 **이미지 한 장으로 만들지 않고** 세 조각으로 나눕니다. 화면 폭이 달라도 크기별 시안 없이 배경만 가로로 늘어나고, 「12월」 같은 달 표시도 텍스트라 매달 바꾸기 쉽습니다.

| 조각 | 전달 방식 | 값 | 화면이 넓어질 때 |
|---|---|---|---|
| 배경 | 코드 | 높이 56, 배경 `#EFE7D8`, 테두리 `#C1C1C1` 1px(안쪽), radius 12, 넘치는 부분 자르기(clip) | 가로로 늘어남 (화면 폭 − 좌우 여백 20씩) |
| 제목 | 텍스트 + **서브셋 폰트** | 「우쑤한국사 {N}월 실록 보기」 조선일보명조 Regular 18 / 행간 25, 자간 −0.2, `#171717` | 왼쪽 20, 위 15 (세로 가운데) 고정 |
| 도장 | **SVG** | `stamp-rotated.svg` 81.78 × 81.78 (15° 회전 적용됨), 위 −7 | 오른쪽에 붙음 (오른쪽 여백 8.22) |

- 테두리는 도장 **위에** 그립니다 (도장이 테두리 밖으로 나간 부분은 잘림).
- **도장 위치 규칙**: 도장 왼쪽 끝 = `max(배너 폭 − 90, 225)`. 225 = 제목 끝(20 + 197) + 8.
  배너 폭이 315보다 좁으면(화면 폭 355 미만) 도장이 제목과 겹치지 않도록 오른쪽으로 밀려 더 잘립니다.
- 배너 전체를 누르면 실록 02 표지로 이동합니다.

## 파일

| 파일 | 용도 |
|---|---|
| `stamp-rotated.svg` | 도장, 15° 회전 적용 — 그대로 배치 |
| `stamp.svg` | 도장, 회전 전 (66.77 × 66.77) — 코드에서 15° 돌릴 때 |
| `ChosunCentennial-banner-subset.ttf` (22KB) | 앱(iOS · Android)용 서브셋 폰트 |
| `ChosunCentennial-banner-subset.woff2` (11KB) | 웹뷰용 서브셋 폰트 |
| `title-01.svg` ~ `title-12.svg` | 제목을 글자 모양 그대로 벡터로 바꾼 것 (1월 ~ 12월). **폰트를 넣을 수 없을 때만** 사용 |
| `preview.html` | 320 · 360 · 375 · 393 · 430 화면에서 어떻게 보이는지 |

### 서브셋 폰트

- 원본 조선일보명조(약 1.2MB)에서 배너에 쓰는 글자만 남겼습니다: `우쑤한국사 실록 보기 월 0123456789` (공백 포함).
- 폰트 이름은 원본과 같은 **Chosun Centennial / Regular**입니다.
- 문구가 바뀌어 새 글자가 필요하면 서브셋을 다시 만들어야 합니다 (없는 글자는 기본 글꼴로 보임).
- 조선일보명조를 앱에 포함해 배포해도 되는지 **라이선스 확인**이 필요합니다.

### 아웃라인 SVG (대안)

- 높이 25(행간과 같음), 폭은 달마다 다름 (12월 기준 약 197). 배너 왼쪽 20, 위 15에 배치합니다.
- 글자가 많아 파일이 70KB 안팎입니다. 폰트를 넣을 수 있다면 서브셋 폰트 쪽이 가볍고 선명합니다.
